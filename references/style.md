# Язык, термины и оформление

## Реестр терминов

Один термин на одно понятие по всему комплекту. Базовый набор — расширять
под конкретное изделие и фиксировать в перечне сокращений РЭ.

| Использовать | Не использовать |
|---|---|
| изделие (в формулировках ЕСКД), машина (в тексте по существу) | агрегат, оборудование, установка вперемешку |
| оператор | машинист, водитель, пользователь |
| орган управления | кнопка, тумблер, рычаг — как общее название |
| рабочий орган | голова, рабочая часть, узел |
| техническое обслуживание (ТО) | сервис, обслуживание, профилактика |
| отказ | поломка, неисправность — как синоним отказа |
| рабочая жидкость | масло — если речь о гидросистеме |
| наработка | пробег, время работы |

Термины «отказ», «критический отказ», «предельное состояние», «назначенный ресурс»
имеют нормативные определения — употреблять их только в этом значении.

## Формулировки

- Указания — повелительное наклонение или неопределённая форма, единообразно
  по всему документу: «Заглушить двигатель» или «Заглушите двигатель», но не вперемешку.
- Требования — «должен», «необходимо». Запреты — «запрещается», «не допускается».
  Рекомендации — «рекомендуется». Не смешивать модальность внутри одного пункта.
- Никаких оценочных слов: «легко», «удобно», «надёжно», «просто», «качественно».
  Это язык коммерческого предложения, в РЭ он неуместен.
- Никаких сравнений с изделиями других изготовителей.
- Каждая операция ТО и ремонта — с критерием выполнения: момент затяжки, зазор,
  уровень, признак исправности. «Проверить состояние» без критерия — пустой пункт.

## Оформление

- Нумерация разделов сквозная многоуровневая: 1, 1.1, 1.1.1. Глубже четвёртого
  уровня не уходить.
- Ссылки на органы управления — по номеру позиции на рисунке: «рукоятка 7 (рис. 3)».
  Номера позиций едины для всего документа.
- Таблицы и рисунки нумеруются и имеют названия; на каждый есть ссылка в тексте.
- Единицы — СИ. Дублирование в дюймах допустимо только в скобках, если узел
  импортный и маркирован в дюймах.
- Предупреждения выделяются и стоят **перед** опасным действием, а не после.
  Три уровня, применять последовательно: ОПАСНО (гибель или тяжёлая травма
  неизбежна) — ВНИМАНИЕ (возможна травма) — ПРИМЕЧАНИЕ (возможно повреждение
  изделия). Не начинать раздел со сплошного блока предупреждений «на всякий случай» —
  их перестают читать.
- Лист регистрации изменений — обязателен, вести с первой редакции.

## Типовые ошибки

- Паспорт и РЭ расходятся в характеристиках, ресурсе или гарантии.
- Раздел «Утилизация» состоит из одной фразы «утилизировать в соответствии
  с законодательством» — требование не выполнено.
- Критические отказы не выделены из общего списка неисправностей.
- ТО покупного двигателя переписано из его мануала с ошибками вместо ссылки
  на оригинальный документ изготовителя двигателя.
- Схема строповки без указания массы и точек подъёма.
- Перечень предупредительных табличек есть, а порядка их замены при утрате нет.
- Заявлены уровни шума и вибрации без протокола измерений.
