# Эксплуатационная документация на машины (ЕСКД + ТР ТС 010/2011)

РЭ и паспорт — это не маркетинговый текст и не перевод чужого мануала. Это документы
с нормированной структурой, которые прикладываются к комплекту подтверждения соответствия.

## Порядок работы

1. **Анкета исходных данных.** Заполнить с изготовителем `references/intake.md`.
   Не начинать текст РЭ, пока анкета не закрыта или пробелы не помечены явно.
2. **Форма подтверждения соответствия.** Найти изделие в Приложении 3 (сертификация)
   или Приложении 4 (декларирование) ТР ТС 010/2011 — от этого зависят реквизиты
   в паспорте и на титульном листе. Форму проверять по действующей редакции регламента,
   не по памяти.
3. **РЭ.** Собрать по `references/re-structure.md` — полная структура частей и разделов.
4. **Паспорт.** Собрать по `references/ps-structure.md` — включая бланки свидетельств.
5. **Аудит.** Прогнать `references/trts-010-checklist.md`. Ни один пункт не остаётся
   без ответа: либо есть в тексте, либо помечен как незакрытый.
6. **Выпуск.** Отдать в DOCX через skill `anthropic-skills:docx`. Стиль и типовые
   ошибки — `references/style.md`.

## Жёсткие правила

- **Не выдумывать нормируемые значения.** Уровни шума и вибрации на рабочем месте,
  масса, назначенный ресурс, срок службы, класс защиты — только из протоколов испытаний
  или расчётов изготовителя. Нет данных — ставить видимый плейсхолдер, а не правдоподобное
  число. Выдуманное значение в РЭ — это дефект, который всплывает при проверке.
- **Не копировать документацию конкурента.** Чужой мануал используется как ориентир
  по составу разделов и по перечню операций ТО. Формулировки, схемы и иллюстрации —
  собственные, по своей машине. Переведённый чужой текст в своём РЭ — нарушение.
- **Каждое утверждение о безопасности привязано к органу управления или к операции.**
  «Соблюдайте технику безопасности» — пустая строка, она не выполняет требование регламента.
- **Плейсхолдеры видимые и одноформатные:** `⟦ЗАПОЛНИТЬ: что именно, откуда взять⟧`.
  В конце работы собирать их список отдельным перечнем для изготовителя.
- **Один термин на одно понятие** по всему комплекту. Реестр терминов — в `references/style.md`.

## Примеры

Плохо — раздел есть, требования не выполняет:

```
2.3 Использование изделия
Работайте аккуратно, соблюдайте технику безопасности.
Уровень звука на рабочем месте оператора — 85 дБА.
```

Нечем подтвердить 85 дБА, а «аккуратно» не является указанием.

Хорошо — конкретное действие, конкретный отказ, честный пробел:

```
2.3.4 Перечень возможных неисправностей в процессе использования

| Неисправность | Вероятная причина | Метод устранения |
|---|---|---|
| Рабочий орган не удерживает отметку в режиме «Авто» | Приёмник вышел из зоны луча; загрязнены окна приёмника | Остановить проходку, вернуть машину в зону луча, очистить окна приёмника ветошью |
| Просадка одной стороны рабочего органа при выключенном двигателе | Внутренние утечки гидроцилиндра | Эксплуатация запрещена. Заменить цилиндр (см. 4.2) |

2.3.5 Уровень звука на рабочем месте оператора — ⟦ЗАПОЛНИТЬ: LpA, дБА,
по протоколу измерений № ___ от ___, ГОСТ 12.1.003⟧
```

Плохо — критический отказ описан как рядовая неисправность:

```
При отказе тормозов остановите машину и обратитесь в сервис.
```

Хорошо — отказ классифицирован, действие персонала задано, критерий предельного
состояния назван:

```
5.1 Критические отказы
Отказ рабочей тормозной системы относится к критическим отказам.
Признак: машина не удерживается на уклоне при отпущенных органах управления ходом.
Действия оператора: заглушить двигатель органом аварийного останова, покинуть
рабочую площадку, оградить машину, не возобновлять работу до устранения.
Критерий предельного состояния: см. 1.1.2.
```
