# gost-ed-mashiny

Agent Skill: составление эксплуатационной документации на машины — руководство по эксплуатации (РЭ) по ГОСТ Р 2.610-2019 и паспорт (ПС) по ГОСТ Р 2.601-2019, с аудитом содержания на соответствие ТР ТС 010/2011. Применяется при составлении, проверке или доработке эксплуатационной документации, руководства или инструкции по эксплуатации, паспорта изделия, формуляра, ЗИП или КДС для машины, станка, строительного или технологического оборудования, а также при подготовке комплекта документов для декларирования или сертификации по ТР ТС 010/2011 (EAC).

Точка входа — [`SKILL.md`](SKILL.md): последовательность из шести шагов (анкета исходных данных → форма подтверждения соответствия → РЭ → паспорт → аудит → выпуск в DOCX), каждый шаг ссылается ровно на один файл из `references/`.

```
SKILL.md
references/   — 5 модулей: анкета исходных данных, структура РЭ, структура паспорта,
                аудит по ТР ТС 010/2011, стиль и терминология
```

**Статус:** отдельный, самостоятельный репозиторий — пока не импортирован ни в одну библиотеку скиллов.
