# Материалы разработки

Этот каталог назывался `docs/` до 2026-09-23 и был переименован в `.dev/`,
чтобы не попадать в поставку. Импортёр библиотеки навыков (`_is_refused_part()`
в `lazy-skill-library/scripts/import_sources.py`) отбраковывает любой путь, у
которого хоть одна компонента начинается с точки, поэтому содержимое сюда
больше не копируется в дерево библиотеки и не попадает в перечень ресурсов
навыка, который агент видит при каждом вызове `read_skill`. Решение и
формулировка — по прецеденту `arbitrazh-ru` (2026-09-19, коммит `339b23a`),
не изобретены заново.

**Старые записи здесь пишут пути как `docs/…`.** Это верно на момент их
написания; читать как `.dev/…`. Записи не правились: исторический документ
помечается, а не переписывается.

**Чего переименование не делает.** Файлы остаются в репозитории и в его
клонах: ведущая точка убирает путь из импорта, а не из git.
